# 页面工作流

这是用户要求融入的五类日常用法。按入口选取相关部分；沿用当前项目的 tokens、组件和接口，修改共享样式前检查受影响的其他页面。分析模式只输出建议，实施模式才修改。已有明确方向或直接实现要求时优先遵循，不额外增加选择环节。

## 1. 已有页面改造

先查看实际页面和相关代码，围绕页面类型、主要用户、核心任务及期望气质进行具体优化：

- **信息层级**：明确重点、主要操作与次要信息，让用户知道页面用途并能迅速开始操作。
- **布局留白**：统一对齐、内容宽度和间距节奏，按内容关系组织区域；不把无关内容机械地套成同样的卡片。
- **排版**：建立标题、正文、辅助文字和数据层级，照顾中文行高、换行和长内容；收敛零散字号及过多加粗。
- **色彩**：背景、文字、边框和强调色各有职责；状态色含义一致，保持文字可读，避免仅靠颜色表达状态。
- **组件**：统一按钮、输入框、表格、标签和弹窗的尺寸、圆角、边框及状态，同类操作保持一致。
- **交互**：主要操作容易发现，按交互打磨部分补齐相关组件的状态与恢复路径。
- **动效**：用轻量变化解释状态、层级和操作反馈，尊重减少动态效果设置，保持阅读与操作顺畅。

完成条件：页面内容和核心功能保留，结构、排版或操作体验有可说明的改善；在允许的实际预览中检查桌面、移动布局和核心路径。仅换色或叠加阴影不足以说明改善，需指出解决了什么具体问题。

## 2. 新页面设计方向

新页面整体视觉尚未确定、且用户未要求直接实现时，先给三个明显不同且适合目标用户的方向：

- 每个方向说明布局与信息组织、配色、字体层级、留白特点、最有辨识度的一处设计，以及与页面用途的关系。
- 用同一段真实或明确标为演示的内容展示核心区域简短预览，保证可比较；差异应体现在构图和视觉语言，不只是换色。
- 使用当前允许的草图、结构示意或局部预览方式，不为比较生成三套完整应用。只允许文字方案时以文字和结构示意比较，不写文件；付费生成、外部上传或指定工具流程服从当前授权。
- 交付候选后等用户选定，再展开完整页面；明确要求自主选择时，简述选择理由并继续。用户已指定方向、已有设计系统或要求直接实现时，基于该方向推进。

完成条件：候选差异与适配理由明确，下一步要展开的方向由用户选择或授权自主确定。

## 3. 参考设计迁移

先提取参考中的构图比例、内容密度、字体层级、间距、色彩、边框、圆角、图片用法和视觉焦点，形成针对目标页面的简短判断：

- 哪些规律适合迁移，能改善目标页面的什么问题。
- 哪些不适合，原因是内容、用户任务、信息密度、品牌或设备条件不同。

再结合当前页面实现，保留用户真实内容、业务功能和品牌，不直接套用参考的品牌、文案及装饰。截图未展示的交互按当前业务流程和现有契约设计，说明影响结果的假设；结构或行为无法确认时标明证据缺口。

完成条件：能解释参考规律与目标页面的对应关系，页面风格协调，原有业务含义和功能得到保留。

## 4. 交互打磨

按真实用户的核心任务走完整条路径，检查本次涉及的内容：

- **入口与下一步**：操作可发现、文案能解释动作，结果和后续步骤清楚。
- **点击与等待**：立即反馈，等待时提供合适的进度或状态，避免重复提交和突然布局跳动。
- **表单**：错误靠近对应字段，说明如何修正；失败保留必要输入，用户能够重试。
- **弹窗**：打开、关闭、初始焦点、键盘操作和关闭后的焦点返回符合现有组件约定。
- **列表与返回**：筛选、切换和返回时保留任务所需的筛选、选择、分页或滚动状态；不要把已失效的状态强行恢复。
- **触屏与窄屏**：主要操作仍可见、可触达，不依赖仅悬停才能发现的功能。
- **反馈与动效**：本次涉及的组件补齐悬停、聚焦、按下、禁用、加载、空数据、成功及失败反馈；状态表达一致，动效提供反馈和方向感，尊重系统减少动态效果设置。

沿用现有请求封装和真实成功条件；网络、HTTP、业务及响应结构失败均不能显示成功。完成条件：核心路径及相应失败恢复有实际行为，交付时明确实际验证过的状态。

## 5. 视觉复核

基于当前实际渲染的页面检查视觉焦点、对齐、排版、留白、组件一致性和操作反馈，并对照本次需求及原有版本判断改进。仅能做代码或截图分析时明确限制，不声称已验证实际交互。

- 按影响排序，默认列出最重要的至多五个有效问题；不足时按实际数量报告，不为数量制造问题，阻断核心使用的问题优先。
- 每项指出具体区域、当前表现、为什么影响使用，以及明确的修改方式，避免只说“更现代”或“增加高级感”。
- 有实施授权时，先修正其中影响最大的至多三项，再查看实际页面；仅评估任务交付建议，不修改文件。仍未满足明确需求或存在核心阻断时继续处理相关问题，不能因为达到数量就结束。
- 修正后确认目标问题有所改善，并检查本次受影响区域是否新增遮挡、溢出或布局跳动。已满足验收就结束，不追加固定美化轮次。

完成条件：重点问题有依据，授权范围内的必要修正已完成或说明阻塞，实际视觉、交互和未验证内容各自说明。
